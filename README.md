# Machete — descargas

**Tu machete digital para entrevistas.** Escucha la conversación, la transcribe
en tiempo real y te sopla la respuesta en un overlay que no aparece al compartir
pantalla.

Este repositorio solo publica los instaladores. El código de la app no es público.

## Descargar

Andá a **[Releases](../../releases/latest)** y bajá el de tu sistema:

| Sistema | Archivo |
|---|---|
| Windows 10/11 | `Machete-Setup-x.y.z.exe` |
| macOS 13+ | `Machete-x.y.z.dmg` |
| Linux | `Machete-x.y.z.AppImage` |

La app avisa sola cuando hay una versión nueva.

> Los instaladores todavía no están firmados: Windows puede mostrar
> SmartScreen ("Más información" → "Ejecutar de todas formas") y macOS pedir
> abrirla desde Preferencias → Privacidad y seguridad.

## Problemas

Abrí un [issue](../../issues) con tu sistema operativo y la versión de Machete.
